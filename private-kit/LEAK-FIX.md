## مرحلهٔ ۲ — ZIPها را از درخت `main` بردارید

بعد از Private شدن، فایل‌ها فقط برای اعضای مخزن قابل دانلودند؛ حالا از `main` بیرونشان بیاورید:

```bash
cd /path/to/pasokhban-dev
git checkout main
git pull
git rm --cached pasokhban.3.2.3.zip pasokhban.3.2.4.zip pasokhban.3.2.5.zip pasokhban-github-repo.zip
git commit -m "حذف بسته‌های نصب و بستهٔ ویترین از مخزن توسعه؛ خروجی بیلد دیگر commit نمی‌شود"
git push origin main
```

بعد `.gitignore` مخزن خصوصی را با فایل همراهِ همین بسته (`.gitignore`) جایگزین یا کامل کنید تا تکرار نشود.

## مرحلهٔ ۳ — پاک‌کردن کامل از تاریخچه (اختیاری ولی توصیه‌شده)

تا این مرحله انجام نشود، فایل‌ها داخل تاریخچهٔ مخزن باقی‌اند و هر عضو مخزن (یا هر کسی که فردا دسترسی بگیرد)
می‌تواند با `git log --all -- pasokhban.3.2.5.zip` بیرونشان بکشد.

```bash
pip install git-filter-repo
git filter-repo --invert-paths --path-glob 'pasokhban.*.zip' --force
git push --force --all origin && git push --force --tags origin
```

**قبل از اجرا بدانید:**

- `git filter-repo` همهٔ commit hashها را عوض می‌کند؛ اگر کسی clone دارد، باید دوباره clone کند و
  pushهای قدیمی‌اش را دور بریزد (`git reset --hard origin/main`).
- `--force` روی همهٔ شاخه‌ها و تگ‌ها لازم است، وگرنه نسخهٔ لو‌رفته در شاخهٔ دیگری زنده می‌ماند.
- پس از force-push، **هر لینک مستقیم ZIP می‌میرد** — از جمله لینک‌هایی که به مشتریان داده بودید.
  توزیع را به کانال مشتری‌محور منتقل کنید: سایت خودمان پشت ورود مشتری، یا لینک یک‌بارمصرف امضاشده.
- فایل‌هایی که قبلاً دانلود شده‌اند **قابل بازگرداندن نیستند**؛ این کار فقط جلوی دانلود آینده را می‌گیرد.
- برای آرامش: قبل از اجرا یک بکاپ آینه‌ای بگیرید (`git clone --mirror` به یک مسیر بیرون از مخزن).

بررسی نهایی که دیگر چیزی نمانده باشد:

```bash
git log --all --oneline -- 'pasokhban.*.zip'    # باید خالی باشد
git ls-files | grep -E '\.zip$'                 # باید خالی باشد
gh repo view Masoumiofficial/pasokhban --json isPrivate
```
